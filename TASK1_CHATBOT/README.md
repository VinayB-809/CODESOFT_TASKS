# Astra - Rule-Based Chatbot

## Description

This project is a simple rule-based chatbot developed using Python as part of the CODSOFT Artificial Intelligence Internship - Task 1.

The Astra responds to user inputs using predefined rules and conditions. It provides basic conversational features such as greetings, date and time, inspirational quotes, jokes, and help commands.

## Features

- Greeting responses
- User name recognition
- Date and time display
- Inspirational quotes
- Programming jokes
- About the chatbot
- Available services
- Help menu
- Chat history
- Exit command

## Technologies Used

- Python 3
- Random module
- Time module
- Datetime module

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

python chatbot.py

5. Enter your name and start chatting with Astra.

## Available Commands

- hello
- about
- services
- date
- time
- quote
- joke
- help
- menu
- exit

## How It Works

The Astra uses predefined rules and `if-elif-else` conditions to identify the user's input and provide an appropriate response.

For example, when the user enters a greeting such as "hello", the Astra selects a suitable greeting response.

## Project Purpose

This project demonstrates the basic concepts of rule-based conversational systems, Python functions, conditions, loops, user input handling, and basic natural language processing concepts.
