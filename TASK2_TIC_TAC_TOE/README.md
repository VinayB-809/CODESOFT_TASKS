# Tic-Tac-Toe AI
## Description
This project is a simple Tic-Tac-Toe game developed using Python as part of the CODSOFT Artificial Intelligence Internship - Task 2.
The game allows a human player to play against an AI player. The AI uses the Minimax algorithm to make intelligent decisions during the game.

## Features
- Human vs AI gameplay
- AI uses the Minimax algorithm
- Human can win
- AI can win
- Draw detection
- Displays available moves
- Simple console-based interface
  
## Technologies Used
- Python 3
- Math module
- Random module

## How to Run
1. Install Python 3.
2. Open the project folder.
3. Run the following command:
python tictactoe.py

4. Enter a number from 1 to 9 to make your move.
## Game Board
1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9
The human player uses X and the AI uses O.

## Algorithm
The AI uses the Minimax algorithm to evaluate possible moves and select a suitable move.

## Project Purpose
This project demonstrates basic Artificial Intelligence concepts, game logic, decision making, functions, conditions, loops, and the Minimax algorithm.
