# Movie Recommendation System
## Introduction
This project is a simple Movie Recommendation System developed using Python as part of the CODSOFT Artificial Intelligence Internship - Task 4
The system recommends movies based on the genre selected by the user. It contains a collection of Indian movies, with a focus on Telugu movies.
## Features
- Allows the user to select a preferred movie genre
- Recommends movies based on the selected genre
- Contains different categories of movies
- Simple console-based interface
- Easy to understand and use
## Technologies Used
- Python 3
- Lists and Dictionaries
- Loops
- Conditional Statements
- User Input
## Recommendation Approach
The project follows the basic concept of content-based filtering. The user's selected genre is compared with the genre of each movie in the dataset. Movies with a matching genre are displayed as recommendations.
## Available Genres
- Action
- Romance
- Comedy
- Drama
- Horror
- Thriller
- Family
## How to Run
1. Make sure Python 3 is installed on your system.
2. Download or clone the repository.
3. Open the project folder in the terminal.
4. Run the following command:
python recommendation.py
5. Select a genre by entering the corresponding number.
6. The system will display the recommended movies.
## Example
If the user selects Action, the system searches the movie list and displays the movies that belong to the Action genre.
